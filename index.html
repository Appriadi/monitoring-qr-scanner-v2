Scanner QR Monitoring Kawasan

Scan QR pengunjung dengan kamera. Setelah token terbaca, kirim token ke aplikasi Monitoring Kawasan agar kolom token terisi otomatis.

Gunakan URL aplikasi utama Google Apps Script, bukan URL scanner GitHub Pages.

Siap. Masukkan URL aplikasi utama, lalu tekan “Buka Kamera”.

Pengiriman hanya mengisi token pada aplikasi utama. Petugas tetap harus memilih aktivitas dan gerbang, lalu menekan “Proses Token”. Token tidak diproses otomatis.
