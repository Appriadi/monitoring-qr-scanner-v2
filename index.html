Scanner QR Monitoring Kawasan

Arahkan kamera ke QR pengunjung. Jika scanner dibuka dari aplikasi Monitoring Kawasan, token dikirim otomatis kembali ke kolom token aplikasi utama.

Siap. Tekan “Buka Kamera” untuk mulai.

Token hanya dikirim ke tab pembuka melalui pesan browser. Jika dibuka langsung tanpa aplikasi utama, gunakan tombol Salin Token.
